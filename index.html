About this dashboard / assumptions

The sample CSV file is located at: supplier-dashboard/data/supplier_performance_granular.csv (relative to wherever you extract the zip file). When you click "Choose File," navigate to that folder.

The uploaded file has 30,000 rows (one per order line), but the table shows one row per supplier — 72 total — since everything is grouped and summarized by supplier.

On-Time Delivery % — compares actual delivery date to the date the supplier promised (not the original requested date). Open and Cancelled orders are excluded since they don't have a delivery date yet.

Reject Rate % — rejected units divided by received units (not ordered units), so it reflects quality of what actually arrived rather than what was originally ordered.

N/A shows up when a supplier doesn't have enough data yet to calculate a metric.

Full write-up of assumptions and data quality notes is in the README file included with this project.
